# Code for chromatin looping analysis

This repository contains the code for all analyses and figures in the manuscript **Inferring chromatin looping interactions from
microscopy-based measurements: opportunities and
pitfalls** by J. M. Jusuf, A. S. Hansen and C. Zechner (2026).

## Overview of analyses

### Polymer simulations
3D polymer simulations of chromatin were performed on the fictitious 2000-monomer (2 Mb) locus described in [Jusuf et al., Nat Struct Mol Biol (2026)](https://www.nature.com/articles/s41594-026-01819-2), following the same methodology with a few modifications outlined here. We analyzed the following subset of 6 loops, chosen to encompass both CTCF-CTCF and CRE-CRE (also referred to as enhancer-promoter or EP) loops while spanning a range of looping probabilities and genomic separations:
| ID   | Left coord. | Right coord. | Type | Size | Looping probability (%) |
| ------ | ---- | ----- | ---- | ---- | ------------- |
| loop_0 | 1604 | 1752  | CTCF | 148  | 7.26          |
| loop_1 | 330  | 574   | CTCF | 244  | 3.33          |
| loop_2 | 724  | 1390  | CTCF | 666  | 3.43          |
| loop_3 | 1640 | 1722  | CRE   | 82   | 3.40          |
| loop_4 | 540  | 745   | CRE   | 205  | 1.35          |
| loop_5 | 833  | 1202  | CRE   | 369  | 1.16          |

We re-ran the simulations (`polymer_simulation_code`) and the MSD calibration (`polymer_simulation_code/MSD_calibration.ipynb`) for this study in order to obtain data at a finer time-resolution. As in the original implementation, we simulated three conditions:
* `no_LE_no_EP`: No loop extrusion, no sticky interactions (for MSD calibration only)
* `with_LE_with_EP`: Loop extrusion, sticky interactions (main simulation)
* `with_LE_no_EP`: Loop extrusion, no sticky interactions (negative control for sticky E/P loops)

For the `with_LE_with_EP` and `with_LE_no_EP` conditions which were used for all downstream analyses, initial burn-in runs were first performed over 5 hours of simulated time. Main runs were performed beginning from the final conformations of the initial runs, saving every block (~20 ms) for a total of approximately 24 hours of simulated time. Only the coordinates of relevant loop anchors were saved as output during this stage. Raw simulation outputs are stored in `data/simulation_data_raw`.

Blocks 1,000,000-4,000,000 (~16 hours of simulated time) of the main runs were then processed in `processing_scripts`. The 2 Mb region was tiled 35 times across the length of the simulated chromosome, generating 35 replicates of all loops from a single simulation; only replicates 10-19 were retained for further analysis. Then, we added varying levels of independent Gaussian noise to all XYZ localizations, with $\sigma$ = 0, 10, 20, 30, 40 or 50 nm in the $x$ and $y$ directions and double this amount in the $z$ direction. Lastly, we extracted the trajectories of 3D distances (defined as Euclidean distance in 3D space) for all 10 replicates of all 6 loops of interest. Processed simulation data are stored in `data/simulation_data_processed`.


### Analyses of polymer simulation data

The following relate to Figures 1, 2, 3, S1, and S2:
* `analysis_code`: scripts to analyze the processed simulation data
* `data/analysis_data`: data resulting from these analyses, which is then plotted in the figures
* `figure_code`: notebooks to plot the figures using matplotlib
* `figure_exports`: SVG files generated by these notebooks
All scripts and notebooks for these figures are written in Python.

### Statistical analyses

The scripts to generate Figures 4 and 5 are contained in `stats_code_matlab`. 

* `PlotThresholdingMetrics.m` was used to generate Figure 4
* `RunBayesianThresholding.m` was used to generate Figure 5. In this script, we simulated a pair of monomers with a separation of $\Delta S=16$ on a Rouse chain with $D=291$ nm<sup>2</sup>/s and $\kappa=1/17$ s<sup>-1</sup>, and generated noisy trajectories with $\sigma = 20$ nm per coordinate at intervals of $\Delta t = 12$ s. These parameters were chosen according to [Gabriele et al. 2022](https://www.science.org/doi/10.1126/science.abn6583) (see its Supplementary Information for more details). Bayesian reconstruction was performed as described in the main text for 1000 trajectories.


## Data

The following large data folders/files can be downloaded from our [Zenodo repository](https://zenodo.org/records/24096051):

* `simulation_data_raw/`
* `simulation_data_processed/`
* `analysis_data/`
* `2022_Fbn2_full_data.h5`  (data from [Gabriele et al. 2022](https://www.science.org/doi/10.1126/science.abn6583), for MSD calibration)

After downloading and extracting them, place them in `data/`. (If you choose to store the data elsewhere, modify `paths.py`, through which all code finds the data files).
